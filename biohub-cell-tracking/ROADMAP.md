# Roadmap

## Phase 1 — Foundation (current)

- Environment and packaging
- Dataset reader (Zarr + GEFF)
- Data models
- Logging and configuration
- Visualization utilities
- Offline evaluation metric
- Submission generator

## Phase 2 — Preprocessing and Benchmarks

- Quantile and intensity normalization pipelines
- Metric benchmarking scripts
- Submission validation

## Phase 3 — Baseline Tracking

- Nearest-neighbor and Hungarian linking
- Kalman filter baseline
- LAP tracker integration

## Phase 4 — Segmentation

- Classical Otsu + watershed
- Cellpose and StarDist wrappers

## Phase 5 — Advanced Tracking

- Ultrack pipeline
- Trackastra integration

## Phase 6 — Division Detection

- Fork detection heuristics
- Lineage graph validation

## Phase 7 — Optimization

- Hyperparameter search
- Memory and throughput profiling

## Phase 8 — Final Ensemble

- Model ensembling
- Cross-validation splits
- Kaggle submission automation
